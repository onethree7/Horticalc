# Documentation Audit - 2026-06-01

Status: historical report.

## Scope

Audited active docs against:

- `src/horticalc/`
- `api/app.py`
- `frontend/`
- `scripts/`
- `.github/workflows/release.yml`
- `tests/`
- shipped `data/` and `recipes/`

The old documentation was backed up to:

```text
_docs_backup/2026-06-01-pre-docs-rework/
```

`_docs_backup/` is ignored by git.

## Findings

### Stale Roadmap Mixed With Current Procedure

`docs/release_build.md` contained an implementation roadmap for tasks that are
now implemented: single-origin frontend serving, launcher, portable data,
PyInstaller onedir packaging, and release workflow. It also referenced
`docs/AGENTS.md` as if it contained runtime specs, but that file only points to
the root `AGENTS.md`.

Resolution: rewrote `release_build.md` as current operational release docs.

### Duplicate GUI Docs

`docs/GUI_PLAN.md` and `docs/GUI.MD` overlapped. One was a plan, one described
current UI behavior. Keeping both active made it unclear whether future agents
should implement or preserve the described behavior.

Resolution: deleted `GUI_PLAN.md` from active docs and rewrote `GUI.MD` as the
current frontend contract.

### Obsolete Feature Stub

`docs/feature_osmosis_mix.md` described osmosis as a feature request, but
osmosis is implemented in `core.apply_osmosis_mix()`, API payloads, water
profiles, and the UI.

Resolution: folded osmosis behavior into `data_model.md`, `api_reference.md`,
and `user_guide.md`; deleted the stub from active docs.

### Stale Golden Output

`docs/golden_example_output.txt` was a captured output blob. The active output
schema now belongs to `CalcResult.to_dict()` and is documented in
`data_model.md`. A static copied JSON blob is too likely to drift.

Resolution: deleted the tracked blob. Use CLI commands to regenerate examples.

### Solver Defaults Drift

Several docs said `relative_weighting=true` was the default. Current code and
tests define `relative_weighting=false` in `src/horticalc/solver_config.py` and
`tests/test_cli_solver_config.py`.

Resolution: updated current docs and decisions to match code. The historical
2026-05-31 deep-run report remains unchanged as historical evidence.

### Current Architecture Missing

There was no single current map showing how the core, API, UI, launcher,
portable paths, and packaging interact.

Resolution: added `architecture.md`.

### API And Data Model Missing

API routes, payload shapes, validation keys, AppRoot data policy, output fields,
and solver output fields were scattered or implicit in tests.

Resolution: added `api_reference.md` and `data_model.md`.

### Anti-Drift Policy Too Weak

The old docs policy said not to duplicate instructions, but did not define
which code files own which truths or what must be updated when behavior
changes.

Resolution: strengthened root `AGENTS.md` and added
`documentation_maintenance.md`.
