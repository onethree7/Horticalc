# HORTICALC GUI (Recipe Wheel Redesign)

Die Oberfläche wurde als dunkles App-Shell-Layout modernisiert:

- Linke Sidebar mit „REZEPT WHEEL“ Navigation.
- Hauptbereich für Rechner, Solver, Wasser und Dünger-Editor.
- Sticky Live-Statusleiste mit NPK, EC25, Ca/Mg und Bilanz.
- Bestehende Tabellen/Expertendetails bleiben erhalten und nutzbar.

Die Frontend-Architektur bleibt statisch (Vanilla JS/CSS/HTML), ohne Framework- oder Backend-Contract-Änderungen.
